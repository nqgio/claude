# Theo Has 100 Days

A fully automated daily animated Shorts series, made end to end by Claude Code:
original character + backgrounds drawn in code, local open-source voices, synthesized music,
automatic posting to YouTube Shorts / Instagram Reels / TikTok, and a story driven by the top comment,
with commenters cast as cameo guests.

- **Story & rules:** `series/bible.json` · **current state:** `series/story.json`
- **How the daily run works:** `CLAUDE.md`
- **Connecting your accounts:** `SETUP.md`

Make a video locally: `bash scripts/bootstrap.sh && python3 scripts/build.py episodes/day-001`
